# VagOS 🐧

**Our own distro by and for the VAGOS crew.**

VagOS is our journey into building and understanding a Linux distribution from the ground up, using Linux From Scratch as our starting point.

We're a group of developers learning systems programming, Linux internals, and operating system fundamentals by building something of our own.

### 🎯 Goals.

- Build our own Linux-based system using Linux From Scratch.
- Understand how a Linux system is assembled from source.
- Learn about the Linux kernel, toolchains, system libraries, and boot processes.
- Develop our own tools and customizations.
- Document our progress, mistakes, and discoveries along the way.

### 🛠️ Project status

🚧 Early development — currently planning our build environment and initial system.
